# Diseño de interfaces — La Estantería

## Pantalla 1: Catálogo
**Objetivo:** listar los libros registrados y permitir buscar por título o autor.

**Información:** título, autor, género, precio y disponibilidad.

**Componentes Jetpack Compose:**
- Scaffold y NavigationBar para la estructura y navegación.
- Column y Row para organizar contenido.
- Text para títulos y datos.
- Card para cada libro.
- LazyColumn para el listado desplazable.
- OutlinedTextField para la búsqueda.
- Spacer y Padding para espaciado.

## Pantalla 2: Autores
**Objetivo:** listar autores y mostrar sus datos.

**Información:** nombre, nacionalidad, biografía y cantidad de libros asociados.

**Componentes Jetpack Compose:** Scaffold, NavigationBar, Column, Text, Card, LazyColumn y Spacer.

## Identidad visual
- Crema: #F5F0E8
- Café: #493629
- Terracota: #B66B4E

Estilo editorial minimalista, tarjetas redondeadas y navegación inferior.
