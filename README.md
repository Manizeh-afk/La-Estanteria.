# La Estantería

Aplicación Android de gestión y consulta de una librería, desarrollada con Kotlin y Jetpack Compose.

## Funcionalidades
- Catálogo de libros con título, autor, género, precio y disponibilidad.
- Búsqueda por título o autor.
- Pantalla de autores con nacionalidad, biografía y cantidad de libros.
- Navegación inferior entre catálogo y autores.

## Modelo orientado a objetos
- `Autor`: representa a los escritores.
- `Libro`: representa los libros y mantiene su disponibilidad.
- `Datos`: centraliza los autores y libros de ejemplo.

## Tecnologías
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Gradle

## Abrir el proyecto
Abre la carpeta raíz del proyecto en Android Studio y espera la sincronización de Gradle. Selecciona un emulador o dispositivo Android y ejecuta la configuración `app`.
